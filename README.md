## About

Nightfall Snake turns the `duartess7` contribution calendar into the familiar Snake animation: it follows the contribution-aware path, eats active cells and loops with the natural pacing of the original GitHub snake.

The animation is generated by the open-source [Platane/snk](https://github.com/Platane/snk) engine. This repository supplies the Nightfall color direction, profile configuration, publishing workflow and embed used by `duartess7`.

## Features

- established contribution-aware Snake solver;
- classic game-like movement and pacing;
- custom gothic purple Nightfall palette;
- animated SVG with no browser-side JavaScript;
- automatic daily refresh through GitHub Actions;
- output ready to embed in a GitHub profile README.

## Pipeline

```text
GitHub contributions → Platane/snk → Nightfall SVG → profile README
```
